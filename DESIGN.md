# Clipper visual system

## Direction

Clipper is a focused workstation for finding and shaping moments from live video. Keep the source video, timeline, and next useful action visually dominant; the interface should stay calm during long editing sessions.

The existing Media → Editar → Entregar → Aprender workflow and its top navigation remain. Use a restrained graphite palette, opaque surfaces, compact system typography, and a warm selection/action accent. Preserve Clipper's color-coded icons so pages, tools, and utility states are recognizable at a glance. Reserve red for recording and errors. Avoid ambient gradients, decorative glass, and motion that competes with the footage.

## Functional color

- Preserve the established icon palette for wayfinding and tool recognition; do not neutralize icons as a performance optimization.
- Keep semantic colors consistent with the icon or state they represent. Static color is separate from blur and animated glow effects.

## Typography and shape

- Use the system sans-serif stack for interface text.
- Use tabular numerals for timecodes, durations, and measurements.
- Keep labels concise and sentence-case; rely on weight and spacing rather than decorative display fonts.
- Use 5–9 px corner radii for controls and panels. Reserve elevation for floating menus and dialogs.

## Surfaces and interaction

- Keep panels opaque and distinguish workspace regions with value and spacing, not blur.
- Use the warm accent for selection, keyboard focus, and primary actions; retain established icon colors as a separate functional cue.
- Keep recording red and success, warning, and information colors muted and semantic.
- Preserve direct editing and immediate feedback. Use short state transitions; honor reduced-motion preferences.
- Preserve the existing responsive navigation and editor behavior.
